\chapter*{ABSTRACT}
\addcontentsline{toc}{chapter}{ABSTRACT}
\noindent
Outdoor navigation in mountain regions can become difficult when satellite positioning is unavailable or unreliable. This project presents camera-based method for estimating location of mountain photographs in the Khumbu region of Nepal. Method uses visible skyline as main source of information. Reference database containing 1.34 million horizon profiles generated from a 30\,m Digital Elevation Model (DEM). A U-Net with a MobileNetV3-Large encoder was then used to separate sky from terrain in input photograph. Detected skyline was converted into one-dimensional elevation profile and compared with reference database. Three matching methods were used to capture terrain features at different scales, and their ranked results were combined using Reciprocal-Rank Fusion. System was also implemented as offline mobile prototype, allowing main processing steps to run without internet connection or satellite positioning. Method was first tested using 300 synthetic photographs rendered under different lighting and weather conditions. Of these, 206 passed quality check and were matched against database. Among answered queries, 86.4\% were localized within 500\,m, with median error of 135\,m. System was then tested on 68 Google Street View panoramas from the Khumbu region. Because many of these images had limited field of view, haze, fog, or weak skyline boundaries, quality and agreement checks were used before accepting result. Seven images passed final checks, and six of these were localized within 1\,km, giving accepted-case accuracy of 85.7\% with median error of approximately 40\,m. These results show that skyline shape can provide useful location information in mountainous terrain, even when satellite positioning is not available. However, performance depends strongly on skyline visibility, image quality, and amount of terrain visible in photograph. System therefore provides approximate location rather than replacement for conventional navigation systems.
